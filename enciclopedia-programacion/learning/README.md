# Práctica inicial en once lenguajes

Los recorridos y enunciados están integrados en los capítulos y las soluciones al final de cada volumen.
Este directorio contiene soluciones completas: intenta primero los ejercicios del PDF.

- **Python**: `python/`; comando desde esa carpeta: `python3 main.py`.
- **JavaScript**: `javascript/`; comando desde esa carpeta: `node main.js`.
- **TypeScript**: `typescript/`; comando desde esa carpeta: `tsc --project tsconfig.json && node build/main.js`.
- **Rust**: `rust/`; comando desde esa carpeta: `rustc --edition=2021 main.rs -o app && ./app`.
- **C**: `c/`; comando desde esa carpeta: `cc -std=c11 -Wall -Wextra -Werror main.c -o app && ./app`.
- **C++**: `cpp/`; comando desde esa carpeta: `c++ -std=c++20 -Wall -Wextra -Werror main.cpp -o app && ./app`.
- **Java**: `java/`; comando desde esa carpeta: `javac Main.java && java Main`.
- **C#**: `csharp/`; comando desde esa carpeta: `dotnet run --project Learning.csproj`.
- **Go**: `go/`; comando desde esa carpeta: `go run main.go`.
- **SQL**: `sql/`; comando desde esa carpeta: `sqlite3 :memory: ".read schema.sql" ".read ex1.sql"`.
- **Bash**: `bash/`; comando desde esa carpeta: `bash test.sh`.

Las pruebas cubren un conjunto finito de casos y no constituyen aprobación académica.
Las carpetas se pueden copiar fuera del repositorio para practicar sin modificar las fuentes del libro.
