# Estándar compartido

Esta carpeta contiene las convenciones editoriales comunes del repositorio.

El objetivo es que cada libro conserve su identidad temática, pero que toda la colección se reconozca visualmente como una misma serie.

## Qué debe compartirse

- estructura de portada;
- paleta cromática base;
- jerarquía tipográfica;
- estilo de capítulos;
- cajas didácticas;
- estilo de figuras y cuadros;
- índices;
- BibLaTeX/Biber;
- índice analítico;
- metadatos PDF;
- convención de ediciones.

## Qué puede variar por libro

- título y subtítulo;
- volumen;
- color/acento secundario si se decide;
- figura técnica de portada;
- capítulos y apéndices;
- bibliografía;
- macros específicas de cada asignatura.

La referencia visual inicial es la Tercera edición de **Estructuras Aeroespaciales**.
