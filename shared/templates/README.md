# Plantilla mínima de metadatos

Al crear un libro nuevo, fija explícitamente:

```latex
\newcommand{\BookTitle}{...}
\newcommand{\BookTitleShort}{...}
\newcommand{\BookSubtitle}{...}
\newcommand{\BookVolume}{Volumen I}
\newcommand{\BookVolumeSubtitle}{...}
\newcommand{\BookAuthor}{Daniel Miguel Tejedor}
\newcommand{\BookEdition}{Primera edición}
\newcommand{\BookDate}{...}
```

La edición se cambia únicamente cuando el libro se publica como una nueva edición real.
