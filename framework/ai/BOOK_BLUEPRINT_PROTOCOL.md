# Book Blueprint Protocol

Antes de redactar un libro nuevo, AeroBooks debe capturar con precisión qué significa “hacer el libro que el usuario quiere”.

## Blueprint mínimo

### Identidad
- título;
- autor;
- edición;
- volumen;
- idioma;
- institución/contexto.

### Audiencia
- curso/nivel;
- conocimientos previos;
- objetivos de aprendizaje;
- profundidad matemática;
- profundidad histórica/científica.

### Alcance
- incluye;
- excluye;
- futuras ediciones;
- límites por falta de fuentes.

### Autoridad
- fuentes prioritarias;
- convenios locales;
- política ante conflictos;
- modo de investigación.

### Didáctica
- orden preferido;
- ratio teoría/problemas;
- derivaciones;
- intuición;
- autoevaluación;
- simulacros;
- formulario.

### Estética
- identidad de colección;
- densidad;
- figuras;
- tablas;
- cajas;
- estilo de portada.

### Reglas no negociables
Todo aquello que una IA no puede cambiar sin permiso:
- notación;
- signos;
- estructura;
- terminología;
- nivel;
- estilo editorial;
- licencias/restricciones.

### Criterios de aceptación
Definir resultados observables:
- índices presentes;
- número mínimo de problemas si procede;
- todas las fórmulas centrales auditadas;
- claims de alto riesgo trazados;
- revisiones independientes;
- compilación limpia;
- inspección visual.

## Regla

Un prompt no sustituye al blueprint. El blueprint es un artefacto versionado del libro.
