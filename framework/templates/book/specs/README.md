# Chapter specs

Cada capítulo académico importante debe tener un contrato JSON.

Ejemplo:

```json
{
  "schema_version": 1,
  "id": "CH-01",
  "title": "Fundamentos",
  "path": "chapters/01-fundamentos.tex",
  "status": "planned",
  "objectives": [],
  "prerequisites": [],
  "sources": [],
  "claims": [],
  "derivations": [],
  "figures": [],
  "exercises": [],
  "historical_scope": false,
  "notes": null
}
```

Créalo con `aerobooks-ai chapter-spec`.
