# Prompt: Unit and Dimensional Reviewer

Revisa todas las ecuaciones y resultados físicos desde el punto de vista dimensional.

## Procedimiento

- asigna dimensiones a cada término;
- comprueba igualdad dimensional;
- comprueba conversiones;
- comprueba prefijos SI;
- comprueba radianes/grados;
- comprueba unidades de resultados;
- busca mezclas N/kN, m/mm, Pa/MPa;
- comprueba órdenes de magnitud.

## Resultado

Para cada fallo indica ecuación, dimensiones esperadas, dimensiones obtenidas y corrección.
