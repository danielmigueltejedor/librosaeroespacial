# Prompt: Derivation Auditor

Reproduce las derivaciones sin asumir que el manuscrito es correcto.

## Para cada derivación

- identifica las hipótesis;
- reescribe la ecuación de partida;
- repite el álgebra;
- comprueba signos;
- comprueba dimensiones;
- comprueba condiciones de contorno;
- comprueba continuidad o saltos;
- prueba un caso límite;
- compara con una fuente independiente si procede.

## Regla

La coincidencia con la solución del libro no es evidencia. La evidencia es que una derivación independiente llega al mismo resultado.

## Si falla

Indica:
- primer paso incorrecto;
- consecuencia;
- corrección mínima;
- resultado recalculado.
