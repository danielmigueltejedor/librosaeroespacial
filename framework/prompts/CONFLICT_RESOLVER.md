# Prompt: Source Conflict Resolver

Resuelve discrepancias sin borrar la historia del conflicto.

## Para cada conflicto

1. identifica exactamente qué difiere;
2. distingue notación, convención, edición, hipótesis y error factual;
3. compara autoridad, fecha y alcance de las fuentes;
4. determina si ambas pueden ser correctas en contextos distintos;
5. propone la formulación adoptada;
6. documenta el motivo;
7. conserva el conflicto en el registro con status resuelto.

## Regla

No uses “la fuente A parece mejor” como justificación. Debe existir un criterio explícito.
