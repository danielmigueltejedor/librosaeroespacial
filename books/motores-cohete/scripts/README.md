# Cálculos y figuras originales

Estos programas auxiliares conservan los modelos originales; **no se ejecutan para compilar o editar el LaTeX**. Para usarlos, instala NumPy, SciPy, Matplotlib, SymPy y Pint en un entorno separado. Los ejemplos CEA de Motores Cohete requieren además NASA CEA 3.3.4.

Las rutas de salida son relativas a la carpeta del libro (`figures/`, `reports/` y, en algunos programas, `evidence/`). Crea `evidence/` si deseas regenerar los datos; esa carpeta no contiene aquí los extractos privados del proyecto original. Una nueva figura o un nuevo resultado requiere revisar sus hipótesis y el texto LaTeX correspondiente.
