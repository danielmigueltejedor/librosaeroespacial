# Figuras y portada

Fotografía RS-68 aportada por el usuario para la portada; el archivo JPG se conserva sin modificar.

Los diagramas y curvas del contenido son originales de la edición. Los PDF vectoriales son recursos necesarios para LaTeX; los SVG y programas auxiliares conservan las versiones editables disponibles. No se han incluido páginas escaneadas ni figuras de apuntes privados.
