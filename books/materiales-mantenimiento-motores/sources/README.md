# Fuentes excluidas de la importación pública

Las copias de apuntes, exámenes, materiales docentes y documentos de terceros recibidos como referencia **no se publican** en este repositorio. Tampoco se incluyen las descargas voluminosas de normativa, manuales y artículos públicos. Las referencias, URL y huellas históricas están registradas en `../evidence/`, con recuperación opcional por `../scripts/fetch_public_sources.py`.

La compilación LaTeX usa las figuras del proyecto y no necesita descargar ninguna de esas fuentes. La ausencia de sus copias locales limita la reproducción de algunas auditorías desde cero; véase el README del libro y los informes originales. No se alteran sus estados de aprobación.
