\textbf{Desarrollo de las magnitudes intermedias.} El determinante característico de una matriz dos por dos es $\lambda^2-\operatorname{tr}(A)\lambda+\det A$. La traza fija dos veces la parte real y el determinante fija $\omega_n^2$; solo después se obtiene el amortiguamiento.\begin{enumerate}

\item Sumar la diagonal.

\[\fitmath{\mathrm{trace}=-0.6-1.4\approx -2\,\mathrm{1/s}}\]

\item Restar productos diagonales cruzados.

\[\fitmath{\mathrm{det}=-0.6\cdot -1.4-1\cdot -3.5\approx 4.34\,\mathrm{1/s^{2}}}\]

\item Parte real de los dos autovalores conjugados.

\[\fitmath{\mathrm{real}=\frac{\mathrm{trace}}{2}}\]

\[\fitmath{\mathrm{real}=\frac{(-2)}{2}\approx -1\,\mathrm{1/s}}\]

\item Frecuencia natural.

\[\fitmath{\mathrm{wn}=\sqrt{\mathrm{det}}}\]

\[\fitmath{\mathrm{wn}=\sqrt{(4.34)}\approx 2.083267\,\mathrm{1/s}}\]

\item Frecuencia amortiguada.

\[\fitmath{\mathrm{wd}=\sqrt{\mathrm{det}-{\mathrm{real}}^{2}}}\]

\[\fitmath{\mathrm{wd}=\sqrt{(4.34)-{(-1)}^{2}}\approx 1.827567\,\mathrm{1/s}}\]

\item Factor de amortiguamiento positivo.

\[\fitmath{\zeta=\frac{-\mathrm{real}}{\mathrm{wn}}}\]

\[\fitmath{\zeta=\frac{-(-1)}{(2.083266666)}\approx 0.4800154\,}\]

\item Pasar pulsación amortiguada a periodo.

\[\fitmath{\mathrm{period}=\frac{2\cdot \pi}{\mathrm{wd}}}\]

\[\fitmath{\mathrm{period}=\frac{2\cdot \pi}{(1.827566688)}\approx 3.438006\,\mathrm{s}}\]

\end{enumerate}
