# Prácticas originales de Mecánica de Fluidos

Se conservan los siete guiones Wolfram Language `.wl`, los cuadernos editables `.nb` y la referencia de comandos. Para ejecutarlos hace falta Wolfram Mathematica o un entorno compatible. Los guiones generan sus propias carpetas de figuras.

La procedencia registra una ejecución original con Wolfram 15.0.1 el 15 de octubre de 2026. La importación al repositorio no repite esa ejecución. Las figuras utilizadas por el manual se conservan en `../figures/`; no se necesitan las salidas históricas para compilar LaTeX.

El código es original. Los cuadernos docentes y exámenes usados como referencia no se incluyen.
